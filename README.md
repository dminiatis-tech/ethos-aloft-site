# ethos-aloft-site

Build output for **ethosaloft.com**. This repository contains only the compiled,
publicly served static site — the same files a visitor's browser already downloads.

- It is **not** the application source.
- It contains no configuration, credentials, or internal documents.
- It is generated by `npm run build` and committed as the deploy artifact.

Built from source commit `d594c9c`.
